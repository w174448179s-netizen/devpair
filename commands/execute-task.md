# 执行单个子任务开发

当前执行子任务：读取 `./tasks/{task文件名}`

## 执行步骤

1. **加载规则**：读取 task 文档中「需加载的规则文件」列出的所有文件，作为权威开发标准
2. **只加载显式列出的规则**：不要主动扫描 `~/devpair/rules/` 下的其他文件
3. **编写代码**：根据 task 文档的需求描述，编写代码和单元测试
4. **自检**：实现完成后逐条检查——代码是否匹配所有已加载规则的全部约束
5. **冲突处理**：如有冲突，优先遵循 `~/devpair/rules/` 中的规范；项目特殊例外应在 task 文档的「额外说明」中已明确标注

## 注意事项

- 生成代码前，确保已读完所有列出的规则文件
- 不要跳过任何规则文件——每个文件都包含硬性约束
- 代码生成后逐条对照规则自检，不是大致看看，是逐条核对
- 如果 task 文档的「额外说明」与通用规则冲突，以额外说明为准（项目特殊需求）
